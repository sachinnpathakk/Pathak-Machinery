# पाठक कृषि एण्ड मेसिनरी स्टोर्स

नेपाली भाषाको responsive, single-page storefront landing page। `index.html` अहिले standalone फाइल हो—CSS, पसलको config र JavaScript सबै त्यसैमा inline छन्। कुनै build step वा dependency छैन।

## पसलको वास्तविक विवरण राख्ने

`index.html` भित्रको `window.SHOP_CONFIG` object मा फोन, इमेल, ठेगाना, खुल्ने समय र Google Maps link भर्नुहोस्। फोन राखेपछि मुख्य सोधपुछ बटनले फोन गर्छ; फोन खाली र इमेल भरिएको अवस्थामा इमेल खोल्छ। अन्यथा विवरण थप्नुपर्ने ठाउँ साइटमै देखिन्छ।

## चलाउने

`index.html` browser मा double-click गरी खोल्नुहोस् वा static hosting मा प्रकाशित गर्नुहोस्। CSS र JavaScript फाइलभित्रै छन्। नेपाली अक्षरका लागि Noto Sans Devanagari र फोटोका लागि बाह्य image/font स्रोत प्रयोग गरिएको छ; ती देखिन इन्टरनेट चाहिन्छ।

फोटोहरू: CIMMYT, Nepal Samaya, Gorkhapatra Online, Nepal Bahas र Water for Women Fund का पृष्ठबाट जोडिएका छन्। प्रकाशित गर्नुअघि प्रत्येक फोटोको प्रयोग अधिकार जाँच्नुहोस् र वास्तविक पसल/उत्पादनका आफ्नै फोटो राख्नुहोस्।
